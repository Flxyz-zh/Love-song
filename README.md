# 🎵 Love Songs – Floating Lyrics Animation

**Love Songs** adalah project Python sederhana yang menampilkan animasi lirik lagu secara interaktif di desktop menggunakan library Tkinter. Project ini terinspirasi dari lagu *Love Songs* oleh Kaash Paige.

Aplikasi ini menampilkan potongan lirik lagu dalam kotak berwarna biru yang bergerak perlahan ke atas layar dengan efek teks yang muncul secara bertahap (*typewriter effect*). Selain itu, terdapat animasi not musik berwarna merah yang melayang dengan gerakan bergelombang untuk menciptakan tampilan visual yang lebih menarik.

### ✨ Features
- **Floating Lyrics:** Menampilkan lirik lagu dalam kotak yang bergerak ke atas layar.
- **Typewriter Effect:** Lirik muncul secara bertahap seperti sedang diketik.
- **Floating Music Notes:** Animasi simbol not musik yang bergerak dan bergelombang.
- **Random Animation:** Ukuran, warna, kecepatan, dan posisi not musik dibuat secara acak.
- **Dynamic Positioning:** Kotak lirik muncul secara bergantian di sisi kiri dan kanan layar.
- **Desktop Overlay:** Animasi ditampilkan sebagai jendela tanpa border dan berada di atas jendela lainnya.

### 🚀 How to Run
1. Pastikan Python sudah terinstal.
2. Clone repository ini.
3. Jalankan perintah berikut:

```bash
python lovesong.py
```
